# 🌊 Marine Dashboard

A smart marine dashboard to track **tides, wind, and weather** — built for real-world coastal use.

---

## 🚀 Features

- 🌊 Tide chart (by hour & date)
- 🌬️ Wind information (speed & direction)
- 🌧️ Weather overview
- 📅 Search data by date
- 📊 Interactive charts (Recharts)
- ⚡ Clean and responsive UI
